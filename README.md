# Nuvio Providers Base

Struttura base per un repository di provider Nuvio.

## Struttura
- `manifest.json` — registro dei provider
- `src/` — sorgenti
- `providers/` — file pronti per Nuvio
- `build.js` — punto di ingresso per la build

Il provider incluso è solo un segnaposto e non effettua scraping.
